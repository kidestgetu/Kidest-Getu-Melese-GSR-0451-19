# Git and GitHub Assignment 1

## Getting Started with Statistical Computing

### 1. Overview

This repository was created as part of Assignment 1 for the course *Getting Started with Statistical Computing*. It demonstrates the use of Git and GitHub for version control, project documentation, and sharing code.

### 2. Objectives

The objectives of this assignment are to:

- Create a local Git repository.
- Make and track changes using Git commits.
- Create a remote repository on GitHub.
- Synchronize the local repository with GitHub using push and pull.
- Write project documentation using Markdown.
- Share the project through a public GitHub repository.

### 3. Repository Contents

- `sample_data.py`: A Python script that creates a sample dataset and produces descriptive statistics.
- `README.md`: Documentation describing the assignment, its objectives, and how to run the script.

### 4. Requirements

- Python 3
- pandas Python library

### 5. How to Run the Script

Install pandas:

```bash
pip install pandas
```

Run the script:

```bash
python sample_data.py
```

The script displays the sample dataset and descriptive statistics for selected numerical variables.

### 6. Version Control

Git was used to initialize the local repository, track project files, and record changes through commits. GitHub was used to host the remote repository and share the project.
